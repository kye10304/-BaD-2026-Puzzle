# Однорядний цифровий пазл

Знаходить найдовший ланцюжок цифрових фрагментів, де останні дві цифри
кожного фрагмента збігаються з першими двома цифрами наступного. Кожен
фрагмент використовується не більше одного разу.

## Запуск

Потрібен Node.js 16+. Залежностей немає.

```
node index.js source.txt
```

Шлях необов'язковий (за замовчуванням `source.txt` поруч зі скриптом).
Фрагменти мають бути розділені пробільними символами та містити щонайменше
2 цифри. Розв'язок припускає, що всі фрагменти однакової довжини (як у
доданому файлі), тому найдовший ланцюжок дає й найдовший рядок.

## Як це працює

1. Кожен фрагмент це ребро орієнтованого графа, вершини якого це пари цифр
   00–99 (перші дві цифри → останні дві цифри). Потрібно знайти найдовший
   шлях, що не повторює ребра.
2. Програма використовує бектрекінг (DFS): починаючи з кожного фрагмента,
   вона послідовно вибирає невикористаний фрагмент, що підходить, іде
   далі та скасовує вибір, коли гілку вичерпано.
3. Відсікання: гілка відкидається, якщо поточна довжина плюс кількість
   невикористаних ребер, досяжних із поточної вершини, не може перевершити
   найкращий знайдений ланцюжок.
4. Підсумковий рядок це перший фрагмент плюс кожен наступний без перших двох
   цифр. Перед виводом ланцюжок перевіряється.
